# P06 离线验收修复

受测基线：`733da91`；失败报告：`p06-offline-20261029-003`。

## 产品修复

- P06 注册仓库使用路径、设备号和 inode 派生身份，Git 公共元数据锁仍只验证路径身份，
  导致工作区准备被拒绝、Attempt 留在 preparing，Runner 未启动且关闭核验失败。
  锁、基线 guard、集成工作区统一支持观察身份，同时保留既有路径身份绑定的兼容性。
  不改写旧绑定，不忽略原生 Git 锁或未确认停止；新旧身份仍争用同一公共目录锁。
- HostClient 的资源和仓库迁移接口改用纯协议入口；纯契约类型和校验器从 protocol 导出。
- Host 能力声明补上已真实接线的 `project.profile.detect`。

## 测试契约同步

- 生命周期正常样本升级到 Host schema 6，保留兼容握手与拒绝未知版本的独立检查。
- 事件、资源、标签和策略查询白名单同步实际 P06 交付；不同可信装配仍声明不同能力。
- stdio MCP 的受信进程适配器被显式允许使用 child_process；其他 runtime 模块的网络/进程限制不变。
- 缺命令和未知脚本按当前基线语义保留 `not_run` 与具体原因，不伪装为执行失败或通过。
- 增加新旧仓库绑定竞争同一 Git 锁的回归；保留伪造身份、跨进程竞争、linked worktree 和原生锁负例。

离线验收不代替 live 或负责人签署，不启用全仓历史回归。最终验收证据由新 run 单独生成，旧失败报告保留。
