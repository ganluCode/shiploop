# 日常开发流程中英双语

按用户授权实施 `global_settings.payload.locale`，支持 `en-US` / `zh-CN`，默认英文。
沿用前面对字段名的约定 `locale`，不另建拼写为 local 的第二套配置。不开放项目覆盖。
新增迁移为已有全局配置补英文默认；没有全局配置时有效默认仍是英文，新配置通过正式
CLI/Host 创建。配置 CAS、能力校验与凭据引用边界保持原有规则。

## 实现边界

- 内置 Markdown 按 locale 分目录；纯目录支持显式 locale 选择、英文回退及模块来源摘要，
  未支持 locale 拒绝。变量与代码标识不翻译，缺少两种资源均失败。
- Task / Planner / Feature 修复准备输入时冻结 locale，写进快照或 manifest 并参与摘要；
  Runtime 系统指导、工具说明、默认回复语言从同一 manifest 选择，不读取执行中的新全局值。
  历史无 locale 输入按旧中文语义恢复，语言变化不能跨输入身份误复用 Session。
- 项目 AGENTS、用户文档、工具输出、历史会话与模型输出保持原文；提示词规定默认回复语言，
  不改变用户明确要求的交付物语言，也不事后翻译历史内容。
- 官方两套 Skills 都提供中英资源；init 读取全局设置后同步选中语言到既有官方目录。
  保留其他 Skill 和业务文档，不声称 Harness 自动加载已验证，不自动重写现有项目。
- 飞书卡片本地化固定标题、字段和说明；通知投影冻结 locale，重试不因切换全局语言变化。
- Feature 执行报告本地化固定展示内容，状态码/ID/原始备注/证据原文不翻译。
  JSON 机器字段保持稳定，CLI 其他帮助和 Host 普通错误不在本轮范围。

## 验证与交付

新增缺省/中文/非法/项目越权配置、数据库迁移、双语资源和回退、语言冻结、Skill 同步、
卡片与报告数据保真回归。使用离线局部测试及 localhost 假模型，不发真实请求或通知。
不提交/push。用户后续要求实际全局配置设为中文：完成构建与验证、确认 Host 空闲后，必要时重启加载新代码，再经正式 CLI 保存完整全局配置，保留其他配置；不自动覆盖已有项目 Skills。
