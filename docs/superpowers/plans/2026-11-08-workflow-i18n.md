# Workflow I18n Implementation Plan

**Goal:** 全局 locale 默认英文，接通 Prompt、回复、Skills、飞书与 Feature 报告。
**Architecture:** 现有设置 payload + 双语 Markdown 目录 + 冻结执行输入与持久通知语言。
**Spec:** `docs/superpowers/specs/2026-11-08-workflow-i18n-design.md`
**Execution:** 单 Agent，不委派，不发真实模型请求/通知，不提交或 push。

## Steps

- [x] 编写 locale 配置、模板选择/回退和双语 Skill 回归，运行确认缺口。
- [x] 接通全局设置与迁移、有效配置及公共客户端兼容。
- [x] 提供中英 Markdown，接通 Task/Planner/修复/Runtime 的冻结语言和回复规则。
- [x] 双语 Skills，init 从全局读取语言并同步。
- [x] 本地化飞书和报告固定内容，保留原始数据与重试语言。
- [x] 定向测试、类型/边界、构建和打包资源验证，记录未执行范围。
