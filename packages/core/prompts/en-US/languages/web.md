## HTML / CSS Standards

- Follow component/style conventions. Prefer semantic structure, keyboard access and accessible names. Escape dynamic content for its context; never inject untrusted HTML.
- Support existing narrow/wide layouts without overflow, occlusion or dynamic layout shifts. Follow established interaction states.
- Change only Task-related pages/styles and run related component/style unit tests. Use screenshots/browser tools only when authorized; do not start full-site E2E or new toolchains.
