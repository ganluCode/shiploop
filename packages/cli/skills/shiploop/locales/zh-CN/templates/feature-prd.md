# F01：功能名称

- 设计状态：proposed（负责人确认后才改为 confirmed）
- 负责人：待指定
- 所属 Phase：[阶段范围](../scope.md)
- 技术设计：[设计](../designs/f01-example.md)（无独立设计时说明原因）
- Host Phase/Feature ID：创建后记录，未创建写未创建

## 目标与非目标

说明用户问题、预期结果、范围内行为和明确不实现的内容。

## 场景与需求

按可追踪编号 R-001 列出角色、输入、操作、输出、边界及错误行为。接口签名和共享约束引用技术设计，不重复维护。

## 依赖与交付物

列出前置 Feature、所依赖的接口与产物、预期修改模块、并发共享资源及合并前提。无依赖写无。

## 验收标准

按 AC-001 列出前置条件、操作与可观察结果，覆盖成功、失败及恢复。人工决策独立列出，不允许脚本通过覆盖人工阻塞。

## 测试范围

- Task：相关单元测试文件或待新增文件。
- Feature：本功能单元测试集合。
- Phase：跨模块集成及受影响回归，引用阶段验收方案。
- 全量 CI：不默认作为 Task/Feature 门禁。

## 风险与待确认

逐项记录问题、影响、负责人、是否阻塞及确认结论；不适用的项目明确写不适用。
