# F01: Feature Title

- Design status: proposed (confirmed only after owner agreement)
- Owner: to assign
- Phase: [scope](../scope.md)
- Technical design: [design](../designs/f01-example.md), or explain why unnecessary
- Host Phase/Feature IDs: record real IDs after creation, otherwise uncreated

## Goals and Non-goals
User problem, outcome, included behavior and exclusions.

## Scenarios and Requirements
Traceable R-001 roles/inputs/actions/outputs/boundaries/errors. Link shared signatures/contracts to one design.

## Dependencies and Deliverables
Predecessor Features, actual required interfaces/artifacts, changed modules, shared resources and merge prerequisites.

## Acceptance
AC-001 preconditions/actions/observable results including failures/recovery. Owner decisions remain separate; automated success cannot override human blocks.

## Test Scope
- Task: related unit files or explicitly pending additions.
- Feature: this Feature's unit-test union.
- Phase: cross-module integration/affected regression via Phase acceptance.
- Full CI: not a default Task/Feature gate.

## Risks and Open Decisions
Record impact/owner/blocking/decision; state not applicable where appropriate.
